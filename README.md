🎮 VelhaQuest é um pequeno projeto em Java inspirado no clássico Jogo da Velha, mas com uma ideia simples de dar um toque mais divertido ao jogo.

Por enquanto, a disputa é entre dois jogadores, com direito a nomes e símbolos próprios. A ideia é ir melhorando o projeto aos poucos, adicionando novas funcionalidades e deixando o jogo cada vez mais divertido.

🏆 E sim... quem sabe no futuro o vencedor não leve aquele lendário troféu de 120 GB de RAM DDR5? 😂
